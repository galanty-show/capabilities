# 本地参考片学习

输入是用户允许本地分析的视频。输出 report.md 六段：测量、三条逻辑线、三层文字、排布、实现缺口、结论与任务卡。原片、抽帧和拼版只留本地，不进入公开仓库。

## 测量

使用已可用的本地播放器、ffprobe/ffmpeg 或用户的分析脚本，不假定存在专有 study 命令。不调用云端分析、OCR、转录或识别服务。按需指定仅覆盖字幕区域的矩形，比较相邻采样帧的亮度差；变化只代表像素改变，不等于识别了字幕。

记录总时长、采样率、差分与切镜阈值、原始命中、合并簇规则，以及间隔中位/P90/最长值。可从 5 fps、归一化平均绝对亮度差 0.02、0.4 秒合并簇作为试验起点；这来自既有工作流，不是通用标准。人工误判标注与原始数字分开，调参数要记原因。比较另一作品时使用同口径。

本地看联系表并播放必要时刻，只记抽象对象数量、关系、顺序、移动、延续和层级：

- 整片论证线：问题、分层、回扣与行动。
- 图内关系线：顺序、选择、关联、确认前后状态。
- 镜头延续线：舞台与对象身份、整体/局部/证据/整体。
- 文字三层：字幕节拍、小标题/单点强调、图内标签；只记长度、时长和频率。
- 排布可用编号流水、发散、汇聚、扇出合并、左右对照、前后变换、列表配证据、三卡、大字陈述等类别，不复制独特画面。

## 输出边界

公开报告用 neutral-id 等中性工作名，不包含参考来源的路径、文件名、平台、标题、作者、链接、台词或可识别画面。方法、参数、人工判断和误差分别写清；没有可重复测量就标未测。

对照目标工程与当前运行时，列“抽象需求 / 现有能力 / 最小缺口”。缺口是建议，不自动授权修改应用。审美与节奏作为可选技巧，不做拒绝制作的门禁。核对六段完整、原始数字保留、拼版确已看过，记录耗时及未验项。

English: Analyze locally and retain only abstract, source-independent timing and layout findings. Separate measurements from judgments, preserve uncertainty, and keep reference media private.
