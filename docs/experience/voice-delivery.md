# 配音阶梯：先保住声音的一致性

配音先看当前 App 的 `galanty://guide/craft` 和 `galanty://environment`。有配置不代表已经试听成功；不要假设用户有密钥、Agent 有某家云工具或所有渠道都能安装本机模型。

## 交付顺序

1. **样片原声与按句缓存。** 没改的句子优先复用原声种子。种子是录音，不能生成新句；改句前确认同一模型/音色仍可调用，只重配变化句。若同源声音不可用，先说明，再决定是否统一更换受影响旁白，避免新旧音色混在一起。
2. **用户已授权的服务或可用云工具。** 可用 App 中已配置的 OpenAI 兼容语音服务，也可用用户的 Agent 已有 TTS 工具。说明会向服务发送旁白文字和预计费用，沿用有效授权；空预算不代表允许付费。先给免费可用方案。
3. **适用渠道的本机神经语音。** 直装版可另装 Qwen 或 Kokoro，先看环境和安装条件。商店版没有本机 Qwen，不让商店用户依赖它；custom-command 也有渠道限制，以环境资源为准。
4. **没有合适声音时继续做字幕与授权配乐。** 告知可配置语音服务、接入云工具或在支持渠道安装神经语音，不自动回退系统语音成片。

项目的交付策略将 macOS say / System voice 限于个人非商业草稿试听，不能默认用它生成交付片。本说明不是对其他系统、声音或未来条款的通用许可判断，实际服务许可仍需核实。

## 一句试音，再做整片

先试语言、音色、发音、语气，确认后按句缓存。普通讲解用一个主音色；角色片按角色固定音色，多语言版分别确认。发音词典只改变送去 TTS 的读法，字幕保留原文。

实配后按真实时长排字幕与动作，再检查停顿、揭示、配乐闪避和切镜。`cue('词')` 在该句有成功逐字对齐时才是实测字时间，否则是句内字数估算；找不到词需要兜底。换音色或语速后重新检查同步，不从旧抽帧推断新声音。

已有作品的小改复用分镜、同源录音及缓存。不要因取回文件失败重新导出；作品成功与下载成功分别确认。

## 如何记录用量

编稿、脚本修订、云配音、AI 图片分别记录工具、模型、调用与费用。本机 TTS 的计算量不等于云 LLM token。日志缺字段写未记录；`tokens used` 只能按该日志实际覆盖范围报告。最新重渲耗时不能冒充初次端到端耗时，程序开发也不算本片制作。

依据：[来源 S1、S2、S3](SOURCES.md)。本篇整理既有策略，未在本轮合成新语音或重新核验第三方服务条款。

English: Reuse original recordings first, then authorized services, channel-compatible neural TTS, or captions and licensed music. Test one line, preserve voice consistency, and measure synchronization against actual audio. System voice remains draft-only in this workflow.
