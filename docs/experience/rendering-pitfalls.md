# 常见坑：确定性、图层、字体、音轨、倍速

下表区分已发生的故障、处理经验与尚未验证的范围。不要把某个工程的修法升级成所有作品的限制。

| 现象 | 记录中的线索 | 最小诊断与处理 |
| --- | --- | --- |
| 同帧重复渲染像素不一致 | S107 曾用 2752 宽大图缩放与运行时 CSS filter；另有 JPEG/transform/混合模式组合 | 同一帧重复渲染比较；试 1920 宽合适底图、离线预调色、PNG/WebP、把混合层移出运镜容器。逐项验证，不能声称禁用所有 filter 才能出片 |
| CODE_NONDETERMINISTIC | 时间、随机或浏览器图层路径可能引入差异 | 动画只依赖帧、fps 和固定种子；检查相同输入、分块和跳帧是否一致。修复后重跑对比，再看真实成片 |
| 3D 翻卡被压平 | preserve-3d 上直接设 opacity/filter | 淡化/模糊移到合适外层，卡片用 backface-visibility:hidden；看翻转中间态 |
| 图片/视频/woff2 或 @fontsource 字体编译失败、样式丢失 | 历史 loader 只处理有限类型，媒体/CSS 输出未交付 | 看实际缺失文件及网络/编译诊断；核对原项目依赖、相对路径、字体和 CSS 输出。修复记录不代表任意外网字体可离线使用 |
| 多音效播放到一半崩溃 | 历史 Player 共享音轨池默认 5 条，外部工程同时挂载第 6 条触发错误 | 核对安装版本、实际并发数与错误。修复曾将池扩到 24 并支持失败子树回拖重试；24 不是所有工程永不失败的保证 |
| 往回拖短 MP3 报 demuxer seek failed | 一个 0.573968 秒音效在原生 HTMLAudioElement 也能复现 | 用独立音频播放/seek 探针核查；检查或替换有权修改的音源。音频失败与画面是否仍可播放分开记录 |
| 节拍逐渐漂移、固定幕多一帧 | 标称 BPM、截歌偏移或固定时长向上取整 | 测实际片段网格，切点量化为帧；复核渲染器舍入方式；换曲同步改分镜与代码 |
| 非 1× 时 Sequence 能力错误 | 新版 Remotion Sequence 的倍速兼容仍在修复清单 | 先用 1× 检查真实时间轴，保留错误与版本，不承诺改预览倍速后导出就相同 |
| 音乐过轻、旁白被盖或削波 | 床乐归一化/音量/闪避叠加；AAC 峰值可能抬高 | 按最终音轨听与测；纯配乐可选歌曲模式；转整数前预留余量，编码后复测真峰值，不照抄旧片增益 |

## 字体也有交付边界

源码写 font-family 不证明字体存在；开发机的系统回退可能掩盖问题。在目标预览/导出环境看中文、英文、数字、字重和换行，保存有权分发的本地字体及许可说明。字体的开源许可不自动覆盖其商标或另附素材。

## 验证范围要具体

编译错误、不可重复渲染或字幕/重要内容越界会破坏成片，应说明后果并修复。配色、镜头密度、推荐停留和响度目标通常是制作建议，不能凭这些拒绝用户的风格选择。

对视觉改动抽查开头、变化中、完成和切前，再正常速度看与听。对声音改动检查真实音轨与 seek，不能用像素截图证明已试听。对来源或授权不明的文件补核或替换，自动报告不证明权利。
