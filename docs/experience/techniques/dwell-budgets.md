# 技巧：先分清“看清”和“读完”

卡点短语与叙事句子需要不同停留。lab 的短语试验用 `0.25 + 0.1 × 单位数` 秒；叙事片试验用 `单位数 / 4.5 + 1.5` 秒。单位按汉字、数字串、英文词计。两者都是创作起点，没有经过所有体裁对照。

给文字事件记时间和类别：cut 新镜头，swap 同位替换，add 保留旧信息的叠加。从揭示后约 0.15 秒到切走/替换量可读时间，叠加不自动终止前文。复杂的多区域文字要分别跟踪，不能用一个全局 swap 粗略算完。

装不下先删重复或低价值信息，再改节奏。卡点硬切一小节、同位替换两拍只是原工作流的建议；刻意蒙太奇可写明意图后照做。有旁白的幕以实际声音和理解需求安排，不硬套两条公式。

lab 总览片曾把章节副题从最长 16 字压到不超过 7 字；这是解决特定短章节卡的做法，不是标题字数限制。报告建议时写依据、实测停留和改法，不阻断渲染。

来源：lab `techniques/dwell-budgets.md` 及总览/故事版制作记录，对应 S095、S099。许可见 [SOURCES](../SOURCES.md)。

English: A short phrase needs recognition time; a narrative sentence needs reading and reflection time. Treat formulas as optional starting points, track replacement per region, and report measured dwell rather than imposing a universal limit.
