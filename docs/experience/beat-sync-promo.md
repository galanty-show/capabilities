# 卡点宣传片：从音乐结构排画面

先有可用音乐和段落，再安排镜头。曲子没有清楚的鼓点，也可以按乐句与情绪变化剪，不必强行拟合固定拍长。

## 两条制作路径

文影中可用纯视觉 `scene.code` 幕、固定时长和配乐；可参考 S095 总览片、S105《改一个字，接着播》、S108《落笔成影》的制作结构。另一条路是本仓库 [HTML 卡点工具包](../../tools/beat-sync-promo/README.md)，适合已有授权歌、需要本地网格适配和离线混音的工程。每支样片的来源与素材许可仍单独核对。

原创合成曲的 BPM、拍点和段落由脚本给定，保留合成脚本和许可。现成曲的拍长从实际使用片段测量，记录 beat0、beat、残差；起音检测只是候选，还需听拍。曲子可用于成片不代表允许混音或单独再分发。

## 从段落到帧

1. 列前奏、铺垫、Drop、间奏、收尾各几小节，大揭示放曲子的结构跃升处。
2. 用网格推导每个切点，再量化成整数帧。跨幕动效用统一全局时间，避免切点相位跳变。
3. 文影固定时长向上取整时，用略低于 `frames/fps` 的秒数保持目标帧数；本仓库 [work-builder](../../tools/work-builder/README.md) 提供这一换算。这是特定管线的舍入适配，不能不经核对套用到所有渲染器。
4. 揭示从拍点起步，大运动落在下一强拍；whoosh 音效峰对最大速度，不只对音频文件开头。
5. 换曲一起更新分镜网格、幕内拍长和段落表。改播放器倍速不会替你重新编排乐曲。

## 停留和音量都靠实际文件复核

短语卡点的一个起点是 `0.25 + 0.1 × 单位数` 秒，cut 间隔一小节、同位替换两拍。叠加可保留旧信息，反复换词会增加负担。时间装不下时先删重复内容；刻意快切由作者决定。这些数字不是所有片型的阅读标准。

床乐会经过归一化、musicVolume 和旁白闪避；纯配乐片想让音乐站前面，可按当前 schema 使用 soundtrack 歌曲模式。历史教师片曾把闪避从较深改成 −4 dB，以保留底乐；它是该片记录，不是所有旁白的推荐值。按最终音轨试听可辨性。

历史作品测到过约 40 ms 的母版音画偏移，并做过局部补偿。这个数不应写成新作品默认值；编码器、封装和管线变化后要重新测量。AAC 编码后真峰值可能抬高，防削波和响度也要看交付文件。
