# S115 羽见 AI 眼镜 · 抬头就是答案

虚构品牌「羽见 PLUMO」AI 眼镜的竖屏卡点宣传片：第一视角钩子 → 五个卖点快切（实时翻译、贴地导航、第一视角拍摄与隐私灯、提词器、消息轻提示）→ “只有 42 克”在配乐刹车里砸下 → Drop 产品亮相、参数逐拍弹出 → 口号标版。正文约 43.4 秒，竖版 1080×1920，平台安全区按抖音预设。品牌、外观与参数全部是演示设定，画面没有真实商标；品类功课、查重与参数依据见 [source.md](source.md)。

## 这支样片演示什么

- **按小节剪的宣传片**：配乐 126 BPM，每幕是定长（小节数 × 1.905 秒，切点按帧取整），切点就是强拍；每幕的 `props.bpm` 与 `props.beatOffset` 给出幕内拍点，HUD 弹出、参数计数、光扫都落在拍上。
- **跟着旁白走的 HUD**：念到“答案”抬头开机、念到“字幕”译文打字、念到“箭头”路面铺出箭头、念到第二个“拍”快门、念到“隐私灯”亮橙灯、念到“讲稿”开始滚动、念到“42”重量砸下；卡点词都是参数（`liftCue`、`cue`、`shotCue`/`shotOccurrence`、`lightCue`、`weightCue` 等），随包旁白带逐字时间。
- **全部代码画的界面**：玻璃面板、取景框、波形、打字、透视导航箭头、快门定格飞入相册、提词滚动、消息卡、粒子、光扫、三维转台、品牌标（原创图形）。HUD 颜色读配色的强调色，播放页换配色时 HUD 跟着换。
- **产品三幕共用一个模块**：`pg-hero` 用 `part`（build / drop / end）切换铺垫、Drop 与标版，产品图只内联一次；参数列表在 drop 幕的 `stats`，弹出的拍在 `statBeats`。

## 可以改什么

- 画面文字全在各幕 `meta.params`：手机消息、HUD 标题、翻译原话与译文、导航距离与路名、拍摄标签、提词稿、消息与来电、重量、参数、品牌名、口号、角注。
- 卡点词改了旁白要一起改；旁白改过的句子没有随包配音（见下）。
- 想换节奏或换曲：同时改分镜各幕 `duration.seconds`、`props.bpm/beatOffset` 与配乐，再播放核对（配乐的音效与旁白段预压是按本片时间轴做的）。

## 素材与声音

- 底图 9 张：Gemini 3 Pro Image 原创生成（人物为虚构形象，产品外观为原创设定）。样片不能引用素材 ID，每幕把自己用到的底图以 900×1600 WebP data URI 内联在 `scenes/*.tsx` 的 `MEDIA` 里；夜市背景招牌与天台广告牌上 AI 生成的字样已离线模糊。提示词、哈希与权利字段见 [media-sources.json](media-sources.json)。
- 旁白：Gemini 3.8 Flash TTS（音色 Zephyr，语速 250，句间 0.12 秒），经“自定义命令配音”合成并逐句做拼音校验；以随包旁白种子形式提供（`templates/samples/narration/S115/`，只在本机与安装包里，不入 Git），播放只读数据、不联网。改了旁白文字，新句子没有这把声音：工作台会提示用本机配音整片重配，或自备 Gemini API key 用同一条自定义命令。
- 配乐：PLUMO Heads Up，Lyria 3 Pro 原创生成后按本片 126 BPM 网格剪辑（一处接缝：律动进场落在第一个卖点、Drop 落在产品亮相），旁白段预压并在 2.7 kHz 让位，叠加 78 处代码合成音效（提示音、打字、快门、whoosh、低频冲击），CC0，随包曲库 `library:original-plumo-heads-up`。
- 响度：导出成片实测约 −19.6 LUFS。管线把旁白定在 −18 LUFS、床乐归一 −18 LUFS 后最多乘 0.5，本片旁白稀疏，整体做不到 −18 以上。
