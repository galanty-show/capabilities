# S117 眠晓智能床垫 · 一夜到天亮

虚构品牌“眠晓”智能床垫（型号“晓一”）的产品宣传片：从凌晨三点醒着的人和一条忽高忽低的睡眠曲线开始，用代码画的数据图讲清四个卖点，到清晨的睡眠报告与产品标版结束。正文约 54.9 秒，横版 1080p。品牌、型号与片中全部读数都是虚构的演示数据，品类卖点与措辞边界见 [source.md](source.md)。

## 这支样片演示什么

- **数据可视化跟着旁白的字走**：睡眠分期带状图按时间光标一段一段画出、念到哪个分期哪一行亮（`stages`）；俯视床面的压力热力图念到“翻身”由仰卧变侧卧，念到“肩膀、腰、臀”逐区高亮、右侧软硬档位跟着调，“托住”时峰值压力降下来（`pressure`）；侧视剖面念到“抬起”床头绕铰点抬 10°、鼾声波形变小（`snore`）；“分区控温”左暖右凉、读数一路走到目标温度（`temp`）；手机报告“得分”起分数一路跳动，落在“八十七”那一帧（`report`）。
- **一条色彩弧线**：顶部的“一夜进度条”从 23:00 的月亮走到 07:00 的太阳，画面从深夜蓝一路暖到清晨金；夜里几幕用宿主 crossfade 的深色过渡，报告→英雄镜头→标版三段暖色改成硬切、在幕内淡到暖白衔接。
- **硬切两侧同一条线**：开场那条忽高忽低的睡眠曲线和品牌幕开头被抚平的金线是同一个函数（`lib` 里的 `jitter`），硬切过去线不跳。

## 可以改什么（各幕 props）

| 幕 | 模块 | 常改的参数 |
| --- | --- | --- |
| hook | `mx-hook` | `clockFrom`/`clockTo` 翻钟时刻、`flipCue`/`wakeCue`/`curveCue` 卡点词、`axis` 时间轴两端 |
| brand | `mx-brand` | `brand` 品牌名、`latin` 拉丁字标、`model` 型号、`brandCue`/`heroCue` |
| stages | `mx-stages` | `heart`/`breath` 读数卡、`stages` 四个分期的名称与卡点词、`chartTitle` |
| pressure、temp | `mx-bed`（两幕共用，`mode` 选画面） | `zones` 七个分区、`adjust` 哪个词调哪一区、`peak`；`sides` 左右两侧名称、卡点词与起止温度 |
| snore | `mx-snore` | `angle` 抬升角度、`loud` 分贝起止、`liftCue`/`calmCue`/`quietCue` |
| report | `mx-report` | `score` 得分、`stats` 四张数据卡、`landCue` 落分卡点词、`verdict` 评语 |
| hero、endcard | `mx-finale`（`mode` 选英雄镜头或标版） | `brand`、`model`、`slogan` 口号两拍（文字与卡点词）、`note` 标版小字 |

换品牌时把 `brand`、`latin`、`model`、`slogan` 一起改，旁白里的品牌名改了要重配音。卡点词找不到时各幕退回固定秒数，画面不会丢。

## 素材与声音

- 底图 7 张：Gemini 3 Pro Image 原创生成，产品外观以夜景英雄图为参考保持一致，人物为虚构形象、不露正脸。样片不能引用素材 ID，所以每张图以长边 1600、质量 60 的 WebP data URI 内联在用到它的那一个模块里（`mx-bed` 两幕共用一张俯视图，只内联一次），全部幕代码合计约 555 KB。提示词、哈希与权利字段见 [media-sources.json](media-sources.json)。
- 数据图、热力图、侧视剖面、温区、手机界面与标志都是代码画的，没有截图。
- 旁白：Gemini 3.8 Flash TTS（音色 Iapetus，语速 235），经“自定义命令配音”合成并逐句拼音校验；以随包旁白种子提供（`templates/samples/narration/S117/`，只在本机与安装包里，不入 Git），播放只读数据、不联网。改了旁白文字，新句子没有这把声音：工作台会提示用本机配音整片重配。
- 配乐：Mianxiao Dawn，Lyria 3 Pro 原创生成后按本片时间轴剪辑（夜段多循环两小节，让“天亮”的整团重击落在旁白“天亮了”的开口），叠加 47 处 NumPy 合成音效（呼吸般的底噪、时钟、提示音、心跳、鼾声、静音电机、跳分滴答、钟声），CC0，随包曲库 `library:original-mianxiao-dawn`。改节奏或换曲后重击与音效不再对齐。
- 字体：宿主随包 Noto Sans SC / Noto Sans（OFL），没有另加字体。
