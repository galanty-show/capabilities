# 让 agent 写画面

想让一句话落进水里，从涟漪中浮出来。模板里没有这一幕，画面只能停在想象里吗？

在文影，写下画面，交给你的 agent。它把描述写成动画，让文字、波纹和出场时机按你的意思组合。

看，文字先落下。圆环从字心推开，光点沿波纹散去。一句话，变成看得见的画面。

想改？换成暖金，节奏再放慢。agent 改写这一幕，新版本从原来的想法生长。

把它放进分镜，配上旁白字幕，在本机渲染成片。下次有新想法，打开文影，让 agent 写出来。
