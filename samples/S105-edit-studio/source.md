# 改一个字，接着播（文影介绍片 · 创作说明，原创）

改一个字，又要等一遍渲染？在文影里，不用等。

这支 58 秒的卡点片只讲文影的三件事，每件事落在一个音乐段落上：

1. 即时预览：样片库里停在封面上就现场播放；打开即时播放器，不渲染视频，本机逐帧现画。按 C 换配色、拖进度条跳到任意一幕、按 V 开关配音、用 [ ] 调节奏，都当场生效。
2. 精确修改：暂停就能看到这一秒是第几幕、在说哪句、用了哪个画面文件；只改一个字，保存后本机更新画面，回到同一秒接着播。导出过的作品有了新改动，导出按钮会提醒“有新改动，重新导出”。
3. 素材管理：导入的每份素材都记着来源、作者与许可；随包曲库里需要署名的曲子会自动写好署名；随包图标导入时自带许可。

播放和修改一直免费。

片中没有旁白，信息全由屏上文字承担；画面里的播放器、样片库、时间条、素材库与导出区都是按真实界面简化重画的示意画面，播放器里播放的《城市之光》与“下周的安排”是示意作品。配乐《Play On》为本片原创、由代码合成。
