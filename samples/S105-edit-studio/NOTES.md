# 改一个字，接着播（S105 · 文影介绍片）

一支 58 秒的无旁白卡点片，只讲文影的三件事：即时预览、精确修改、素材管理。界面全部用代码画出来（不用截图或录屏），近黑底 + 文影荧光绿单一强调色。英文版是 S106《Fix a word. Play on.》（[`../edit-studio-en/`](../edit-studio-en/README.md)）。

- 规格：1920×1080，30 fps，正文 58.07 秒（1742 帧），7 幕全部 `scene.code`、硬切。导出时按权益自动接约 4.9 秒品牌片尾（`brandOutro: "made-with"`），合计约 63 秒。
- 不配旁白，没有宿主字幕；信息全由屏上文字承担。`settings.json` 写 `language: "zh"`。
- 幕代码读 `props.theme`：即时播放里换配色会整片生效；原配色写在 `settings.theme`。
- 文字与画面原创，许可 MIT；配乐《Play On》原创代码合成，CC0。来源与片中事实的出处见 [CREDITS.md](CREDITS.md)。

## 文件

| 文件 | 作用 |

## 节拍与配乐

- 《Play On》：124 BPM，E♭ 大调，和弦 E♭–B♭–Cm–A♭，33 小节 63.87 秒。结构 前奏 2 → 铺垫 4 → Drop A 8 → 间奏 4 → 铺垫二 4 → Drop B 8 → 收尾 3。正文最后一拍音乐停顿、反向铺底吸进片尾；收尾 3 小节垫在品牌片尾下，三声拨弦按 made-with v3 片尾的落点放置：播放键弹出（+0.62 秒）、结果行落定（+3.0 秒）、徽章出现（+4.06 秒），铃音落在徽章那一下；管线在全片最后 1.5 秒统一淡出床乐，徽章那一下已在淡出段里。
- 拍点由 `synth.py` 写定（不是实测），第 0 小节从 0 秒开始。节拍写死在幕代码里：换曲，或在即时播放里调节奏之后，拍点就对不上了。
- 停留按“0.25 秒 + 每字 0.1 秒”核过：分段字幕每条停留 ≥ 8 拍（约 3.9 秒），大字落拍后都留 ≥ 2 拍。
