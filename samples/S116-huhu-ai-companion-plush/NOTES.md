# S116 呼呼 · AI 陪伴玩偶宣传片（虚构品牌）

2026 年中国 AI 陪伴玩具品类的产品宣传片：会聊天、讲故事、陪练英语、记得小事、难过时安慰，家长端可设时长、可查聊天记录。品牌“絮光”、产品“呼呼”、外形与参数全部虚构。正文约 52 秒，横版 1080p。

## 这支样片演示什么

- **表情灯跟着话走**：呼呼说话时眼睛按逐字时间一字一亮（`talk()` 读 `sentences[].words`），右侧发出声波；不说话时缓慢呼吸。眼睛位置写在每幕的 `EYES_*` 常量里（底图像素坐标换算到 1920×1080）。
- **代码画的道具**：绘本翻页与开门、星星飞出、对话气泡、字母块、记忆卡与发光记忆线、蜡烛火苗、窗上雨丝、家长端手机界面（滑块、聊天记录、加密说明、晚安开关）、卖点标注（身高标尺、电池充满、肥皂泡），全部跟旁白卡点。
- **一份底图一条运镜跨两幕**：开场“悄悄话”（无旁白、固定 1.6 秒）和“眼睛亮了”共用 `hh-night`，后一幕 `props.clock` 写前一幕时长，镜头接着推，硬切看不出接缝。
- **情绪抬升**：配乐在“去抱抱妈妈”之后抬起，画面同时化进拥抱。

## 可以改什么

画面文字与卡点词都在各幕 `meta.params`，工作台里直接改：

| 幕（模块） | 参数 |
| --- | --- |
| 悄悄话 / 眼睛亮了（`hh-night`） | 孩子的悄悄话、眼睛亮起秒数、故事选项（图标 + 名字）、飘出卡点词 |
| 睡前故事（`hh-story`） | 产品名、品牌副标题、翻页 / 开门 / 星星飞出卡点词 |
| 陪练英语（`hh-english`） | 念错的样子、安慰气泡、单词（字母块）、念对的气泡、星章文字与卡点词 |
| 记得小事（`hh-memory`） | 记忆卡（图标、标题、内容、卡点词，最多 3 张） |
| 难过的时候（`hh-comfort`） | 孩子说话的气泡、倾听卡点词、玩偶台词识别词 |
| 家长放心（`hh-parent`） | 界面标题、在线状态、手机时间、已陪伴分钟、时长上限原值/拨到、聊天记录（3 条）、隐私说明、晚安开关文字、示意说明 |
| 产品英雄镜头（`hh-hero`） | 材质、身高、续航、外套说明与各自卡点词、示意说明 |
| 结尾标版（`hh-end`） | 品牌名、品类、口号与卡点词、说明 |

换成别的产品：改画面文字参数和旁白即可；换外形要重新生成底图（提示词在 [media-sources.json](media-sources.json)）并改 `EYES_*` 坐标。

## 素材与声音

- 底图 9 张：Gemini 3 Pro Image 原创生成的绘本风插画，先定玩偶与小满的设定图，其余用参考图保持一致。样片不能引用素材 ID，所以每幕把自己用到的底图以长边 1600、WebP q55 的 data URI 内联在 `scenes/*.tsx` 的 `MEDIA` 里（每张图只进一个模块）；制作任务里同名素材槽优先。
- 旁白：Gemini 云端配音，随包是预先生成的旁白种子（`narration/S116/`），播放不联网、不需要 key。旁白 Gemini 3.8 Flash TTS（音色 Leda）；呼呼的台词换成 Gemini 2.5 Pro TTS（音色 Laomedeia，cute 风格），由制作目录的 `voice-map.json` 按整句匹配。每句合成后转写成拼音与原文逐音节比对，不一致自动重来。改了旁白文字，新句子没有这两把声音：工作台会提示用本机配音整片重配。
- 配乐：Huhu Lullaby，Lyria 3 Pro 原创生成后按本片时间轴剪辑并合成音效，CC0，随包曲库 `library:original-huhu`。安静段、弦乐抬起和各处音效对准本片的句子时间：改节奏或换曲后不再对齐。
- 字体：只用宿主随包的 Noto Sans SC（OFL）。
