# S108 落笔成影

文影的水墨宣传片：墨滴落纸，毛笔写下“文影”；四首唐诗随朗读一字一字落纸，念完化成水墨画；在画上把“明月”改成“落日”；墨爆，红日、“落笔成影”。正文 68.5 秒，横版 1080p。原作在 `works/ink-promo/`（本机，不入库），这里是可复制、可改的样片版。

## 怎么拆的

原作是一个全局大模块：七幕共用 `ink-shanshui.tsx`，画面只由全片秒数决定，靠注入的时间表（`TL`）驱动。样片版按幕拆开，每幕只看自己的句子时间：

| 幕 | 模块 | 时间从哪来 |
| --- | --- | --- |
| drop 墨滴落纸（2.1 秒纯画面） | `ink-open`（part=drop） | 幕内秒数 |
| title 落笔写“文影” | `ink-open`（part=title） | 第一句开口落笔；墨晕接着 drop 幕；幕末 0.85 秒内缩成左上落款 |
| p1～p4 四首诗 | 随包模板 T23 `ink-poem-painting` | 第一句是介绍；诗句那句按逐字时间落纸；化画 = max(念完 + 0.3 秒, 幕末前 3.35 秒) |
| edit 明月改落日 | `ink-edit` | 第一句开口出光标，+1.25 秒点选，+2.5 秒出检查器；末句开口前 0.05 秒应用；幕末前 0.4 秒墨爆 |
| finale 尾声 | `ink-finale` | 从墨爆起：钤印 1.25、标语 2.5、英文名 3.75 秒（配乐拍点） |

所以改诗、改旁白后，字跟着新的朗读落纸、化画跟着新的句尾走；换画面类型、换诗人、换落款都是 props。画面上的说明文字（片名、印文、小字、标语、检查器的标题与按钮）都在各幕 `props` 里，并在幕代码 `meta.params` 声明。

- 相邻两首诗之间是 1.25 秒交叉淡化（`overlap: "trim"`）：原作里下一首的介绍压在上一幅画的淡出上，拆开后由转场重叠来做；p4 → edit 同一幅松月图交叉淡化，edit → finale 0.4 秒。
- `ink-open`、`ink-edit`、`ink-finale` 由 `tools/production/ink-promo-20261007/build_scenes.mjs` 把 T22/T23 的共用段（笔画遮罩、印章、溅墨、山、松石）拼进各幕正文（幕代码不能相对导入）；改正文请改 `tools/production/ink-promo-20261007/src/`。

## 声音

- 旁白：原片的本机 Qwen3-TTS 朗读（Uncle_Fu 加诗词朗诵语气，介绍句加快 15%），以随包旁白种子提供（`templates/samples/narration/S108/`，不入 Git），播放不联网、不需要配音模型。种子由 `tools/production/ink-promo-20261007/voice_seed.py`（自定义命令配音）把 `works/ink-promo/voice/trim/` 的音频按句拼出：两行诗拼成一句，行间静音按原片时间表。改了旁白文字，新句子没有这把声音，工作台会提示用本机配音整片重配。
- 配乐：《落笔》（`music/synth.py`，96 BPM，D 羽调五声，纯代码合成，CC0，随包曲库 `library:original-luobi`）。原作是“歌曲模式”：朗读混进整轨、配乐在说话时让位。样片机制不支持歌曲时间轴（soundtrack 需要素材 ID，旁白种子也不在歌曲模式下使用），所以改成旁白 + 配乐两轨：配乐是同一张时间表的器乐版，工作台按 `musicDuckDb: -8` 闪避。
- 对齐：`settings.sentencePauses`（6 处句间停顿）与各幕 `hold` 由 `tools/production/ink-promo-20261007/build_storyboard.mjs` 按原片时间表反推，让每句旁白落在原片同一时刻、化画落在半小节强拍。改字、改停顿或换曲后拍点不再对齐。
- 尾声的“文影，落笔成影”比原片早约 1.1 秒（样片的幕首留白固定 0.4 秒，没有“句前停顿”），现在与白字“文影”落笔同时。

## 英文版（Ink Becomes Image）

S108 有中英两个语言版本（index 的 `languages: ["zh","en"]`），英文只在 [locales/en.json](locales/en.json) 里覆盖：

- 保留中文：四首诗的书法、诗题与作者、落款与印文、“文影”毛笔片名——它们是画面本身。印章按 2×2 印格排字，拉丁字母会被截成四个，所以印文不换。
- 换成英文：片名与副题、各幕旁白（介绍句 + 诗句英译，每句 ≤45 个字符，免得管线拆段合成）、字幕（随旁白）、检查器标题与按钮、尾声标语 “Ink Becomes Image”（没有汉字时 `ink-finale` 改用衬线斜体、不截到 8 字）。
- 配音：本机 Qwen3-TTS 预置英文音色 Aiden（`english_storyteller`），语速 230，随包旁白种子 `narration/S108-en/`；中文版按句 id 记的 `sentencePauses` 在英文版清空。
- 配乐《落笔》共用；英文旁白时长不同，拍点不再与旁白对齐。英文旁白不念中文诗，T23 的逐字落纸退回“在幕长里匀开”，字与英文朗读同时写出。正文约 72 秒（中文 68.5 秒）。

## 已知差异与限制

- 宿主给每句旁白都配字幕，诗句也会出现在字幕带里（原片只给介绍句配字幕，诗句只写在纸上）。
- 毛笔字用 macOS 自带“行楷 Xingkai SC”，印章字“魏碑 Weibei SC”；其他系统回退楷体，字形与手写笔顺不再贴合（落定后整字照常显示）。
- 交叉淡化期间上一幅画从开始重叠就逐渐变淡（原片停满 1.5 小节再在 0.55 秒内洗掉）。
- “点哪 · 改哪”卡片是示意界面，不是工作台真实截图；“落日松间照”是演示修改的结果，不是原诗。
