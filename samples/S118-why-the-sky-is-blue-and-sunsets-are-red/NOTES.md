# S118 为什么天空是蓝的，夕阳是红的

约两分钟的物理科普讲解：白光是一道彩虹 → 空气分子按 1/λ⁴ 散射 → 蓝光比红光多散射 5.86 倍 → 天被染蓝 → 为什么不是紫色 → 光程变长、夕阳变红 → 云为什么是白的 → 彩蛋：火星的蓝色日落。正文约 120 秒，横版 1080p、30fps。

**画面里没有任何图片或视频素材**：天空、日面、海面倒影、光谱、光子和云的颜色，全部由幕代码按物理模型逐帧算出来。这一支用来展示“写画面代码”能做到什么程度。

## 这支样片演示什么

- **同一个模型画所有的天**：`sky-open` 开场把太阳从 62° 拖到海平面，`sky-sunset` 用光标把太阳从头顶拖到地平线，`sky-open` 收尾的四格（正午、日落、白云、火星）都调用同一个天空函数 `skyRadiance()`；画面上的十六进制色值就是当帧算出的结果。
- **光子统计“染”出天色**：`sky-photons` 的 `sky` 幕里，每个光子按太阳光谱抽波长，自由程 ∝ λ⁴、散射角按 1 + cos²θ 抽样；被弹开的光子按波长计数（右上直方图，虚线是理论预期），计数的颜色积分出来就是大气带的底色。
- **公式逐项出现**：`sky-light` 的 `formula` 幕念到“强度”“波长”“四次方”“反比”依次亮出 I、λ、4、∝1/，再逐步代入 (700÷450)⁴ = 1.556⁴ ≈ 5.86，下方是按光谱着色的 1/λ⁴ 曲线和 5.86 : 1 的方块对比。
- **逐字卡点**：太阳落到地平线落在“三十八倍”，天空换成模型天空落在“染蓝”，火星取景框落在“好奇号”；卡点词都是 `meta.params`（如 `landCue`、`dyeCue`、`roverCue`），改了旁白要一起改。
- **确定性**：随机全部用固定种子（`seeded`），光子轨迹在加载时一次算好，第 n 帧只按“年龄”取位置，不依赖上一帧；天空先按 16 像素网格算颜色，再在 CPU 上双线性插值逐像素写入（不用 GPU 缩放）。

## 物理模型与简化

- 颜色：太阳光谱用 5778 K 黑体；光谱 → XYZ 用 CIE 1931 色匹配函数（Wyman–Sloan–Shirley 2013 解析拟合）；XYZ → sRGB（D65）；以大气层外的阳光为白点。
- 地球天空：两层平行平面单次散射——上层空气分子（瑞利，550 nm 光学厚度 0.0975，严格按 λ⁻⁴；真实空气约 λ⁻⁴·⁰⁸），下层薄霾（光学厚度 0.04，Ångström 指数 1.3，Henyey–Greenstein g = 0.76），平流层臭氧 Chappuis 带（约 300 DU，让黄昏天顶保持蓝色）；光程用 Kasten–Young 1989 公式（地平线 37.9 倍）。
- 没有算的：多次散射、地面反射、地球曲率对天空亮度的影响、太阳光谱的夫琅禾费吸收线；曝光像相机一样随天空亮度自动调整（Reinhard 色调映射、保色相）；日面只取透射光谱的色相，亮度另行压缩。
- 为了看得清而放大的：“染蓝”一幕大气带的光学厚度（约真实整层大气的 3.6 倍，各波长比例不变）、棱镜的色散（柯西系数约 6 倍）、日落图解里的大气厚度（读数仍用真实光程）、日面大小。
- 火星：整层尘埃光学厚度 0.5；30% 的散射进入宽度 ∝ λ/d（d ≈ 3 μm）的衍射前向峰，其余为宽角散射，尘埃吸收蓝光用反照率 0.38→0.98 的线性近似。火星画面是模型示意，不是探测器照片（画面上写明）。

事实出处、算出来的数字与核对见 [source.md](source.md)。

## 可以改什么

- 画面文字：每个模块的 `meta.params`（片名两行、读数名称、光谱色名、四格标题、拍摄记录、画面声明等）。
- 卡点词：`*Cue` 参数，改旁白时同步改。
- 物理参数（光学厚度、霾、尘埃粒径、曝光）在幕代码顶部的常量里，改了要重新看画面。
- 片段用法：同一个模块按 `props.part` 分幕（`sky-open`: hook/title/recap；`sky-light`: prism/scatter/formula；`sky-photons`: sky/violet/cloud；`sky-sunset`: sunset/mars），复制一幕的画面时连模块一起复制。

## 已知限制

- 天空模型是单次散射，地平线附近偏暗处用远山或海面遮住；黄昏天顶的颜色依赖臭氧近似。
- 数学字母用系统衬线字体（Times New Roman/Times，缺时回退 Noto Serif 或 Georgia），不同系统字形略有差异。
- 幕代码每帧要算几千个方向的光谱积分，渲染比普通幕慢（样片标为重场景）。

制作脚本、成本账与复现步骤在 `tools/production/code-sky-20261013/`。
