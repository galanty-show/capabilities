# 栖云相册 · UI 开场动效（S122 · GitHub 热门工程改编）

一支 12 秒的方版产品界面开场动效（UI sting），虚构 App“栖云相册”。七段在原作的帧边界上硬切，切点两侧保持同向运动，读起来像一个连续镜头。画面全部由幕代码按帧画出，无旁白。

- 规格：1080×1080，30 fps，正文 12.33 秒（370 帧），7 幕 `scene.code`；导出时按权益接约 4.9 秒品牌片尾，合计约 17.2 秒。
- 配乐：随包曲库 `library:external-project-utopia`（《Project Utopia》，congusbongus，CC0）。导出的交付成片另用本片专配的配乐（见“声音”）。
- 幕代码读 `props.theme`：即时播放里换配色会整片生效。

我们改了什么（Apache-2.0 第 4 条要求说明修改）：

1. GSAP 时间线改写成按帧求值的 React 幕代码：`F(n)` 帧号、`EO/EI` 缓动、打字表、里程表、高亮条逐帧轨迹、轻推缓动表都照原作搬过来；七个 clip 拆成七幕，幕切点就是原作的 clip 边界。
2. 品牌层整个替换：标志（渐变方块里一朵云托着太阳）、导航与菜单图标、箭头光标都是本片自绘 SVG；原作的 HeyGen 标志、HyperFrames 字标、手形光标、TT Norms Pro / ABC Solar Display 字体都不使用，改用宿主字体。
3. 尾卡从 0.7 秒延长到 2.2 秒，内容由“Made with HyperFrames”改为本片的口号与产品名；扫光改为只扫过产品名字形（`background-clip: text`）。
4. 画布从 720² 改为按画幅等比放大（方版 1080² 为 1.5 倍）。

## 幕表（帧号沿用原作）

| # | 幕 | 帧 | 动作 |
| --- | --- | --- | --- |
| A | 标志弹入 | 0–35 | 标志由小放大，图形与字标反向阻尼弹跳，随后加速上冲出画 |
| B | 登录卡 | 35–72 | 卡片自下而上减速入场（接住上一幕的向上运动），按钮扫光，向左加速出画 |
| C | 输入账号 | 72–113 | 放大的登录卡从右滑入、由虚变实，邮箱逐帧打字（三处故意停一帧），向上出画 |
| D | 一个关键数字 | 113–154 | 数据卡入场，里程表逐帧跳到 5,278（个位带纵向拖影），向右出画 |
| E | 导航与高亮 | 154–209 | 五行导航错峰滑入；高亮条一口气从第 1 行滑到第 3 行，路过第 2 行减速不停 |
| F | 新建一下 | 209–304 | “新建”按钮落定，光标滑入按下，菜单从按下处展开，高亮逐格下移，整屏缩远 |
| G | 尾卡 | 304–370 | 口号两段与标志错拍弹开再合拢，一道光扫过产品名，停留到品牌片尾 |

## 可改参数

产品名、登录卡标题与按钮、打字内容（请用 example.com 这类保留域名）、关键数字与说明、五项导航、按钮文字与四项菜单、尾卡口号。导航与菜单的高亮固定停在第 3 项，高亮条宽度按文字自动重算，时间不变。

## 声音

- 随包样片：CC0 曲《Project Utopia》（氛围铺底，不卡点）。随包曲库已接近体积上限，本批不新增曲目。
- 交付成片（本机 `works/`，不随包）：Lyria 3 Pro 原创曲剪辑 + NumPy 合成界面音效（风声峰值压在六个切点上、逐字键声、里程表滴答、鼠标按下/弹起、菜单弹开、尾卡扫光），脚本见 `tools/production/github-html-20261013/s122-qiyun/music_build.py`。

## 已知限制

- 运动模糊用运行时 `filter: blur()`（原作的做法）；本机两轮逐像素复渲一致，换机器或浏览器版本后需重新跑交付检查。
- 品牌片尾是深色底，接在浅色尾卡后会有一次明暗跳变（片尾由应用统一提供）。
- 只做了方版与中文。
