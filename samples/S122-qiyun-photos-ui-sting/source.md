# 栖云相册 · UI 开场动效（创作说明，改编）

这支 12 秒的方版开场动效改编自 HyperFrames 官方发布片仓库里的可换品牌模板 `heygen-apple-motion/01-ui-sting`（Apache-2.0，Copyright 2026 HeyGen, Inc.）。原作是一个产品的界面开场：标志弹入 → 登录卡 → 输入账号 → 一个关键数字 → 导航 → 点一下“新建” → 菜单 → 尾卡，七段在精确的帧上硬切，切点两侧保持同一方向的运动，读起来像一个连续的镜头。

本片把品牌层整个换掉，运动一帧不改：

- 虚构产品“栖云相册”（一个整理照片的 App）。标志、图标、光标都是本片自绘的 SVG；产品名、口号、按钮、导航、菜单与数字全部是本片原创文案，如与现有产品重名纯属巧合。
- 七段的帧号、缓动（只用一族减速/加速曲线，不回弹）、逐帧打点的打字节奏、里程表、高亮条轨迹都照原作；原作尾卡只有 0.7 秒就结束，本片延长到 2.2 秒让产品名读得清。
- 不使用原作的字体（TT Norms Pro、ABC Solar Display）、HeyGen 标志与光标素材；字体用宿主字体。

片中邮箱写的是保留域名 example.com，不是真实地址。配乐用随包曲库的 CC0 曲目《Project Utopia》；导出的成片另用本片专配的 Lyria 原创曲与代码合成的界面音效（不随包，见 README）。

画面文字与关键参数都在各幕 `meta.params` 里，改字、改数字不用动代码。
