# Zelqio — DEMO / 示例产品文档

**虚构产品，仅用于展示发布片技能。Fictional product; not available for installation.**
Zelqio 是为本示例编写的本地开发工作流工具概念：开发者保存一组输入，重放工作流，
比较变化，再给同事一份可读的审阅包。这里的功能、命令和步骤都是虚构设定，
不是已发布软件、实测能力或第三方背书。画面从第一帧到最后一帧保留 `DEMO / 示例`。
无需安装 Zelqio；下列命令只作为画面文案，绝不执行。

## Four stages

`capture → replay → compare → report`：Capture 将示例输入与工作流描述存为一个 trace；
Replay 读取保存的输入；Compare 并排展示前后结果；Report 将输入、差异和检查结果打包。
数字 **4** 仅指这四个命名步骤，不代表速度、增长、用户量或兼容所有开发工具。
画面步骤轴 STEP 01 / 02 / 03 是操作顺序，不是虚构的历史发布节点。

## Local replay

虚构命令 `zelqio replay ./demo`：使用固定输入演练本地工作流，保留每一步的 trace。
示例 4×4 网格展示 **16 个示意 trace**，用于表达批量审阅，
不是实测并发、上限、每秒吞吐量或性能承诺。这里只宣称设定中的可重复输入，
不保证任何真实外部服务的确定性。

## Review bundle

虚构命令 `zelqio report ./demo`：审阅包包含输入快照、结果差异与可读报告。
片中的 “Keep the trace” 指这项虚构功能，不是数据保存/安全承诺。
“Capture. Replay. Review.” 是本示例原创口号。几何 Z 标识与代码界面均为原创绘图；
不使用真实产品 Logo、截图、客户名单或背书。
