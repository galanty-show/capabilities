# Bun — sourced editorial demo

Verified against official pages on 2026-10-21. This is an independent motion-design
study, not an official Bun advertisement. All interfaces and the geometric B
monogram are original illustrations, not screenshots or Bun's mascot/logo.

- https://bun.sh/docs identifies runtime, package manager, test runner and bundler
  in a single binary. **4 tools** counts those four categories; it is not a speed,
  adoption, revenue or time-series measurement. The animated counter counts the
  named categories, with no fabricated historical curve.
- https://bun.sh/docs/test documents `--concurrent`. The 4×4 window grid is a
  **16-test illustrative workload**, not measured throughput or a concurrency limit.
- https://bun.sh/docs/bundler/executables documents `bun build --compile` and
  standalone executable output. No claim of universal Node.js compatibility.
- Release history: https://bun.sh/blog/bun-v1.0 (2023-09-08),
  https://bun.sh/blog/bun-v1.1 (2024-04-01),
  https://bun.sh/blog/bun-v1.2 (2025-01-22). Selected historical milestones, not
  a claim that 1.2 is the latest release.
- https://bun.sh/docs/installation lists `npm install -g bun`. It is displayed,
  never executed by the toolkit.

“Build. Test. Ship.” is our editorial slogan, not a quoted product tagline.
No third-party music, brand artwork, benchmark figures or downloaded imagery.
